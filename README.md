# TALVOA

Monitoramento inteligente de impressoras com Agent local, API em nuvem, dashboard web, multiempresa, unidades/setores e relatórios de consumo.

## Versão de produção

**TALVOA 1.0.0** — baseline técnico de produção.

## Estado atual

- Dashboard, autenticação e portal do cliente
- Multiempresa e Control Center
- Agent Windows com coleta recorrente
- Inventário resiliente a snapshots parciais
- Histórico diário de impressão
- Relatórios por período, unidade, setor e impressora
- Exportação em Excel e PDF
- Monitoramento operacional de Agent, API, impressoras e alertas
- Backup privado com validação de restauração
- Pipeline de testes, segurança, lint, build e smoke test

## Operação

Produção permanece com deploy manual para preservar o uso do plano gratuito e evitar builds desnecessários.
